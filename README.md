# DEAD ZONE ONLINE

브라우저 기반 실시간 마피아 게임의 시작 프로젝트입니다.

## 실행 방법

1. Node.js 18 이상 설치
2. 이 폴더에서 터미널 실행
3. 아래 명령 실행

```bash
npm install
npm start
```

4. 브라우저에서 `http://localhost:3000` 접속
5. 한 명이 방을 만들고, 나머지는 방 코드로 참가합니다.

## 같은 와이파이에서 접속

서버를 실행하는 컴퓨터의 내부 IP 주소를 확인한 뒤 다른 기기에서
`http://컴퓨터의IP주소:3000` 으로 접속합니다. 운영체제 방화벽에서 3000번 포트 허용이 필요할 수 있습니다.

## 인터넷으로 원격 접속

이 프로젝트를 Node.js를 지원하는 호스팅 서비스에 배포해야 합니다.
호스팅 서비스에서 `npm install` 후 `npm start`를 실행하고, 제공되는 HTTPS 주소를 참가자에게 공유하세요.
Socket.IO/WebSocket 연결을 지원하는 호스팅을 사용해야 합니다.

## 포함 기능

- 방 생성 및 코드 참가
- 실시간 참가자 목록과 위치
- 서버 측 비밀 역할 배정
- 가상 구역 이동
- 미션 수행 및 점수
- 마피아 비밀 채팅 / 전체 채팅
- 같은 구역에서의 마피아 공격
- 긴급 회의 및 투표
- 팀 전체 미션 진행도와 최종 탈출 코드
- 게임 종료 및 역할 공개

## 중요: 테스트용 MVP

이 코드는 실제 온라인 플레이 흐름을 확인하기 위한 기본 버전입니다.
아직 완성된 상용 게임 서버는 아닙니다.

배포 전에 다음을 추가하는 것을 권장합니다.
- 계정/재접속 인증과 방장 이전
- 라운드 타이머 및 서버 측 라운드 전환
- 역할별 능력의 완전한 서버 판정
- 미션 중복 완료 방지와 개인별 진행도 검증
- 최종 암호를 개인별 완료가 아닌 팀 전체 진행도로 검증
- 신고/차단, 채팅 제한, 방 비밀번호
- 서버 재시작 시 게임 복구 또는 정상 종료 처리

현재 게임은 메모리 기반이므로 서버를 재시작하면 진행 중인 방이 사라집니다.
